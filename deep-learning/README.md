| [`ROADMAP.md`](./ROADMAP.md) | The full curriculum, Stages 0–11. Every topic has a summary + **🗣️ say-it-aloud self-check questions** — answer them out loud, without notes; fluent = pass. | Your daily driver, start to finish. |
